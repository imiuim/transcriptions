大家好，欢迎回到新一期的 Re-Factoring UI。今天我们要来看看 Jonathan Hillis 提交的一个案例。Jonathan 是 wespecstudent.com 的市场总监，这是一个为加拿大各地学生提供健康福利的项目。他希望帮忙优化计划详情页面——这个页面列出了所有可供学生选择的保障选项。接下来，我们就看看能做些什么来清理这个页面，让它看起来更专业一些，那我们就直接开始吧。

首先我想和大家讨论的是这个页面上的“滚动劫持”问题。所谓滚动劫持，是指网站通过固定滚动点等方式，让滚动条的行为变得与众不同。滚动劫持是一个颇具争议的话题，虽然它在营销页面上或许能营造出炫酷的效果，表现不错，但在这样的实用型页面上却并不合适，所以我们打算把它去掉。此外，页面上的固定滚动点会将用户带到包含计划详情的各个部分。在当前设计中，用户既可以滚动到每个部分，也可以使用页面顶部的标签页进行切换。这可能会有些突兀和出人意料，主要是因为选项卡通常会用来切换视图。这种交互还会在表格内部产生一个别扭的滚动条，因为表格有固定的高度，所以刚好能适配视口。因此，我们要做的就是将这些内容整合起来，移除最大高度限制，让包括页眉在内的所有内容都显示在一个页面上，这样用户就可以轻松地滚动和浏览了。好的，现在这个问题解决了，我们就有了重新绘制后的起点。接下来，我们要首先看一下背景中的校园照片。目前这些照片显得有些喧宾夺主，尤其是在“规划详情图表”上。因此，我们决定将其从该区域移除，但希望将照片保留在页眉位置，因为它能为页面增添一些个性，而且我认为展示用户当前所在学校的照片是件好事。不过，我们需要对照片进行一些处理，以使前景元素与背景之间形成更高的对比度。在处理这类背景照片时，我喜欢做的一件事就是降低其饱和度，然后使用“正片叠底”混合模式叠加一种醒目的颜色。在这种情况下，我将使用学校的主色调——红色。通常，我会在图形设计软件中应用这种处理效果，就像我现在在 Sketch 中演示的那样，然后再进行导出。不过，你也可以通过 CSS 实现同样的效果。我为此创建了一个 CodePen，并在描述中提供了链接，你可以去查看。现在，由于我们不再需要在页眉和计划详情之间使用滚动劫持（scrolljacking），我会稍微收紧一些布局。这样做的好处是，它能将选项卡推送到视口上方（above the fold）。正因为如此，右侧这个色彩丰富的导航栏就显得有些重复且多余了。因此，我们直接将其移除，因为它分散了用户对页眉中其他元素的注意力。好的，现在我们来看一下层级结构。目前，页面标题被隐藏在右上角，而公司徽标则位于下方，与其他所有元素挤在一起。这似乎有些本末倒置，因为公司本身是所选学校的主管方。因此，我们将重新调整这些元素的结构，把徽标放在顶部工具栏中，页面标题则置于其下方。不过在此之前，我们要把顶部工具栏设为白色，并反转其他元素的颜色，因为徽标在白色背景上效果最好。我们还会在这里添加页面标题，将其设置为30像素的大号清晰字体。同时，我们会继续优化细节。好的，让我们仔细看看这些带有灰色占位符的卡片。如果你仔细观察这些卡片，会发现它们分为两类：选择加入和选择退出选项，以及快速链接（可导航至你的空间中可找到的各个部分）。区分这两者非常重要，因为其中一类远比另一类重要，那就是选择加入和选择退出选项——这些选项正在倒计时，显示距离你能够进行修改还剩多少天。事实上，这些选项至关重要，因此在当前设计中，当你在页面滚动时，总能在右下角看到它们。因此，我们将重新排列这些元素，以突出选择加入和选择退出选项，同时确保它们在用户滚动页面时仍能保持在视口内，以便用户随时注意到它们。为了实现这一点，我们将通过添加一个统一的深色遮罩层来整合这一区域。这里我将使用黑色，并将其不透明度降低到 60%，然后在该遮罩层内创建两行内容。第一行将包含所有的快速链接，我们将通过移除图标并将其改为常规样式的较小文本，来弱化这些链接的视觉重点。第二行则通过一条边框与之分隔，用于放置“选择加入”和“选择退出”选项。这一行会稍高一些，以便同时容纳标签和剩余天数信息。仅凭这一点，就已经能够突出这些选项了。但为了进一步强化这些元素的视觉效果，我们不会移除图标。这里有一个关于使用此类图标的小技巧：像这种细节并不算特别丰富的图标，原本是为较小尺寸的场景（例如应用内体验）设计的，并不适合放大到较大的尺寸。因此，我们不向这里展示的那样放大图标，而是保持其常规大小，并将其置于一个圆形容器中，以营造出更大的视觉效果。此外，我们还将对这些图标进行更新。目前这个网站正在使用
